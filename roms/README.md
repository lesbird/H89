# ROMs

These are built into the Mac app and installed next to the Windows program.
Files are recognised by the Heathkit part number in their names (raw
binaries only; the `.hex` files are Intel HEX copies and are ignored):

| Part | ROM |
|---|---|
| 444-142 | MTR-90 monitor (the default) |
| 444-62 | MTR-89 monitor |
| 444-19 | H17 floppy boot ROM |
| 444-46 | H19 terminal firmware |
| 444-29 | H19 character generator |
| 444-37 | H19 keyboard encoder (not used: the keyboard is emulated directly) |
| 444-84 | MTR-84 monitor (not used yet) |
| MMS 84A | Magnolia Microsystems monitor (not used yet) |
